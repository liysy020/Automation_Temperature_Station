A central monitor to all network temperature and humility sensors. This project suitable for Comms room monitoring in business.
Sensors runs over wifi. They report data to the server. Depends on the sensor type it can monitor the temperatore and humility of outdoor and indoor environment. It can also have LCD display showing current time as display on your desk (I uploaded a simple 3D print model for the desk display verson).
The project needs ESP32 running with micro Python. Tested 3x different types of outdoor and indoor temperature and humility sensors. A 2 x 16 LCD display (Optional).
The sensor will need to register to the server in order to obtain a rendom generated API key. Communication running over SSL provides a secure channel.
